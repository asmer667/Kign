# KeyGen — مولّد أزرار لوحة المفاتيح (FUTO Keyboard)

تطبيق أندرويد يولّد أصول أزرار (Key Borders) بصيغة FUTO Keyboard:
عادي / مضغوط / منبثق / زر المسعة، مع تخصيص كامل للألوان والحدود والتوهج والحواف.

## البناء عبر GitHub Actions (بدون كمبيوتر)

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد إليه.
2. ادخل تبويب **Actions** في المستودع — ستجد سير عمل `Build APK` يعمل تلقائيًا.
3. بعد انتهائه (≈5 دقائق) افتح run ناجحًا ثم **Artifacts ← keygen-apk**.
4. نزّل ملف `app-debug.apk` على هاتفك وثبّته.

## الاستخدام

1. اضبط الألوان (الأساس، اللمعة، الظل، التوهج) والمنزلقات.
2. جرّب القوالب: معدني / توهج أزرق / مسطّح.
3. اضغط أزرار التصدير — الصور تُحفظ في: **الصور/KeyGen**.
4. المقاسات: 128×140 (أو ×2/×3/×4 حسب دقة التصدير)، والمسعة 384×140.
5. أدخل الصور في محرر ثيم FUTO ضمن **Other assets** ثم اربطها بالـ matchrules في `theme.txt`.

## في الهاتف بدون GitHub؟

استخدم تطبيق **AIDE** أو **APK Builder** أو موقع CI مثل Bitrise/FlutterFlow لا يناسب —
الأسهل هو GitHub Actions كما في الخطوات أعلاه.
